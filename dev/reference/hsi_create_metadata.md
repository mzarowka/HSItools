# Create structured hyperspectral metadata

Create structured hyperspectral metadata

## Usage

``` r
hsi_create_metadata(
  name,
  sensor_type = NULL,
  manufacturer = NULL,
  nrow = NULL,
  ncol = NULL,
  nlyr = NULL,
  xres = NULL,
  yres = NULL,
  et_target_ms = NULL,
  et_white_ms = NULL,
  target_start_mm = NULL,
  target_stop_mm = NULL,
  session_id = NULL,
  wavelengths = NULL,
  fwhm = NULL
)
```
