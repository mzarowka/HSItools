# Composite hyperspectral indices plots Can composite line profiles and SpatRasters

Composite hyperspectral indices plots Can composite line profiles and
SpatRasters

## Usage

``` r
hsi_plot_composite(x, plots, ...)
```

## Arguments

- x:

  a SpatRaster with REFLECTANCE file. Used for correct placement.

- plots:

  a list of plots.

- ...:

  additional arguments.

## Value

a plot.
